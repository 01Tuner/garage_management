# Garage Management for ERPNext
# Diesel pump / injector workshop module for Scope Technical Trading EST

## Features
- Service Job with Kanban-by-Status tracking
- Billing items (service charges + spare parts) → Quotation → Sales Order → Sales Invoice
- Stock deduction on Sales Invoice submit (`update_stock`)
- Garage Workspace with KPIs and charts
- Print formats: Receiving, Inspection, Service Report
